# CineHub — Movie Website

CineHub is a movie website developed as a web development project. It combines a frontend interface built with HTML, CSS, and JavaScript with backend functionality implemented in PHP.

## Technologies Used

* **HTML5** — Website structure
* **CSS3** — Styling and layout
* **JavaScript** — Client-side interactivity
* **PHP** — Backend development
* **MySQL** — Database (if used in the project)
* **XAMPP** — Local development environment

## Features

* Movie website interface
* Interactive frontend components
* Backend functionality using PHP
* Local development and testing using XAMPP

## Getting Started

### Prerequisites

* XAMPP installed on your computer
* A web browser
* A code editor such as Visual Studio Code

### Installation

1. Clone or download this repository.

2. Copy the project folder into the `htdocs` directory inside your XAMPP installation.

3. Start Apache from the XAMPP Control Panel.

4. Start MySQL if the project uses a database.

5. Open your browser and visit:

   `http://localhost/CineHub/`

6. If the project uses a database, import the provided SQL file into phpMyAdmin and configure the database connection as needed.

## Project Structure

The project contains frontend files (HTML, CSS, and JavaScript) and backend PHP files.

The exact folder structure depends on the project files.
